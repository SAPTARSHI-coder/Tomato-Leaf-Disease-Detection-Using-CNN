# Tomato Leaf Disease Detection

A CNN-based tomato leaf disease classifier with training code, prediction tools, datasets, and project materials.

## Project files

- `train_model.py` — model training workflow
- `predict.py` — prediction entry point
- `app.py` — application entry point
- `dataset/` and `dataset_binary/` — image data
- Reports and presentation files — project documentation

Review the dataset and model configuration before training. No accuracy or clinical claims are implied by this project.
